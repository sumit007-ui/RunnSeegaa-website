This repository contains the high-contrast luxury **Coming Soon Landing Page** built with HTML5, Vanilla CSS, and modern JavaScript 3D Parallax physics.

## 💻 Local Development

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/your-username/RunnSeegaa-website.git
   cd RunnSeegaa-website
   ```

2. **Run Locally**:
   Open `index.html` in your browser or run a local static server:
   ```bash
   npx serve .
   ```
